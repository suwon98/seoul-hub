# Swagger UI 내 Authorize 자물쇠 버튼 누락으로 인한 인가 API 테스트 차단 문제

### 1. 현상 (Issue)
- 백엔드 시큐리티 설정을 통해 `GET /api/v1/congestion` 엔드포인트를 인증 회원 전용 경로로 안전하게 잠그는 데 성공했으나, 스웨거 대시보드 상에서 이를 테스트하기 위한 JWT 토큰 입력 폼(`Authorize` 버튼)이 화면에 렌더링되지 않아 API 실동 테스트가 불가능해짐.

### 2. 원인 분석 (Root Cause)
- 스프링 부트 시큐리티 내부에만 인증 로직을 심었을 뿐, 문서화를 담당하는 Springdoc OpenAPI 인터페이스 엔진에게 "우리 아키텍처는 Bearer JWT 인증 체계를 채택했다"라는 메타데이터 스펙 지시어를 전달하지 않아 스웨거 뷰어가 인증 버튼을 숨겨두었던 아키텍처 설정 누락 사고임.

### 3. 해결 방안 (Resolution)
- `global/config/OpenApiConfig.java` 구성 클래스를 신규 생성하여 `OpenAPI` 빈을 생성하고, 여기에 `SecurityScheme.Type.HTTP` 및 `bearerFormat("JWT")` 사양을 글로벌 바인딩함으로서 스웨거 대시보드 우측 상단에 자물쇠 인터페이스를 강제 기동 및 노출시킴.

### 4. 재발 방지 및 교훈 (Prevention & Lesson)
- 보안 엔진의 변경 사항은 문서화 자동화 툴체인(Swagger)과 항시 실시간 동기화되어야 함. 인프라 방어선을 구축할 때는 클라이언트나 테스터가 이를 명확히 인지하고 조작할 수 있도록 OpenAPI 스펙 데코레이터를 선제적으로 동형 조립해 주어야 협업 병목을 예방할 수 있음.
