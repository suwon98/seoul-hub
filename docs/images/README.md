# 화면 자료와 촬영 범위

2026-10-19, 배포된 Seoul Hub 화면을 격리된 Chrome 브라우저로 촬영했다. 애플리케이션 코드나 운영 계정·게시물을 변경하지 않았다. 지도 검색은 일반 사용자와 동일하게 관심 거점을 등록하므로 기존 수집 예산 안에서 갱신이 발생할 수 있다.

| 파일 | 촬영 범위 |
| --- | --- |
| dashboard.png | 운영 공개 대시보드와 실제 저장 관측 |

| account-demo.png | 계정 조회 응답을 demo@example.com으로 대체한 UI 시연 |

샘플 응답은 브라우저 요청 가로채기로만 제공했다. 인증 우회가 서버에서 가능하다는 의미가 아니며, 실제 로그인·메일 발송·게시물 저장·회원 탈퇴를 수행하지 않았다. 샘플 화면에는 시연 표시가 있다. 모든 이미지의 지도 출처 표시는 유지했다.

메일 링크의 토큰, 쿠키, API 키, 비밀번호, 실제 회원 이메일은 캡처하지 않았다. 정적 화면은 동작 검증을 대신하지 않으며 계정 기능 검증 범위는 [보안 문서](../security-review.md)를 따른다.
